Text&Code Edit+ — Full Documentation

Welcome to Text&Code Edit+

Text&Code Edit+ is a high-performance web-based editor built for both document drafting and full-stack software development. It blends a robust visual rich-text canvas with a full-featured CodeMirror editor supporting over 20 programming and data languages.

Smart Language Engine

Automatic syntax highlighting and extension detection for JS, Python, Rust, Go, C++, SQL, YAML, and more.

Automatic Local Persistence

Every keystroke is preserved in local browser storage to prevent accidental data loss.

Core Features & Shortcuts

  • Magic Wand Code Formatter: Automatically cleans up indentation in code modes, or parses and pretty-prints minified JSON structures with a single click.
  • Live Preview Pane: Real-time browser preview rendered for both HTML files and Markdown (.md) documents using marked.js.
  • Intelligent File Saving: Automatically attaches the correct extension (e.g., .py, .yaml, .rtf) based on active language selection.

Supported Language Modes

Text&Code Edit+ provides full syntax highlighting, bracket matching, and auto-closing tags across these categories:

Web Languages JavaScript (.js), HTML (.html), CSS (.css), PHP (.php)
System & Application C++, C#, Java, Python (.py), Go, Rust (.rs), Ruby
Scripting & Markup Bash/Shell, PowerShell, Lua, Markdown (.md)
Data Formats JSON, CSV, XML, SQL, YAML (.yaml, .yml)

Rich Text Visual Document Editor

Switching the top mode dropdown to Rich Text (.rtf) unlocks a full WYSIWYG word processor panel:

  • Style Hierarchy: Normal Paragraphs, Title (H1), Subtitle (H2), Headings 1-3.
  • Typography: Bold, Italic, Underline, and pixel-precise Font Point Sizing.
  • Paragraph Formatting: Left, Center, Right Alignment, and Bulleted / Numbered lists.
  • Link Insertion: Highlight text and press the link icon to embed hyper-links.

Side-by-Side Search & Replace

Press Ctrl + F (or Cmd + F) or click the magnifying glass in the toolbar to open the side-by-side panel.

• Find Next: Press Enter inside Search input or click Next Arrow.

• Find Previous: Press Shift + Enter or click Up Arrow.

• Replace Current: Enter replacement text and click "Replace" or hit Enter in Replace input.

• Replace All: Click "Replace All" to execute a global document replacement.
